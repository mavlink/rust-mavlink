Expand description

An instance-backed MAVLink dialect.

Unlike Message, a dialect can obtain its message definitions at runtime. Implementations provide the CRC extra byte required to validate a frame and decode its payload into their message representation.

The generated, compile-time dialect API continues to use Message and is adapted internally to this trait by the reader implementation.

Return the CRC extra byte for message_id, if the message is known.

This lookup is required before decoding because MAVLink incorporates the CRC extra byte into the frame checksum.
